# MINE CONTROL — V1 Starter

Монгол хэл дээрх ил уурхайн бүртгэл, мэдээллийн системийн эхний суурь төсөл.

## Баталгаажсан шийдвэр
- Уурхайн төрөл: ил уурхай
- Тээврийн бүртгэл: рейс
- Мэдээлэл оруулах: гараар + Excel импорт
- Зураглал: эхний хувилбарт 2D
- Үндсэн үйлдвэрлэлийн нэгж: м³
- Data Event: тусдаа систем; энэ төсөлд DB эсвэл кодын түвшинд холихгүй
- UI: хар дэвсгэр + MAK шар

## Стек
- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase Auth + PostgreSQL (дараагийн холболтын шат)
- Excel импортын интерфейсийг дараагийн итерацид нэмнэ

## Ажиллуулах
```bash
npm install
cp .env.example .env.local
npm run dev
```
`http://localhost:3000` хаягаар нээнэ.

## Supabase
`supabase/migrations/0001_initial_schema.sql` файлыг шинэ Supabase төслийн SQL Editor дээр ажиллуулна.
Одоогоор бодит Supabase URL/key тохируулаагүй бол UI demo горимоор ажиллана.

## Дараагийн алхам
1. Шинэ GitHub repository-д энэ төслийг оруулах.
2. Supabase шинэ project үүсгэж migration ажиллуулах.
3. Vercel шинэ project-ийг GitHub repo-той холбох.
4. Auth, RLS, бодит CRUD-ийг идэвхжүүлэх.
5. Excel import, 2D уурхайн зураглалыг үе шаттай нэмэх.

> Энэ starter нь туршилтын эхлэл. Үйлдвэрлэлийн бодит бүртгэлд нэвтрүүлэхээс өмнө эрхийн бодлого, аудит, нөөцлөлт, өгөгдлийн баталгаажуулалт, хэрэглэгчийн UAT заавал хийнэ.
