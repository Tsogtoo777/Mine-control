# Архитектурын шийдвэрүүд — MINE CONTROL

## Баталгаажсан
- Ил уурхай.
- Тээврийн хэмжүүр: рейс.
- Үндсэн үйлдвэрлэлийн нэгж: м³.
- Гараар бүртгэх + Excel импорт.
- Эхний газрын зураг: 2D.
- Монгол UI, хар дэвсгэр + MAK шар.
- Data Event тусдаа систем, тусдаа өгөгдлийн сантай хэвээр.

## Тооцооллын зарчим
- Рейс нь тоо хэмжээний хэмжүүр; автоматаар тонн эсвэл м³ болгон хувиргахгүй.
- Хүдэр, хөрсний эзлэхүүнийг тусад нь хадгална.
- Олборлолт, ачилт, тээвэрлэлт, буулгалтыг тусдаа үйл явдал гэж загварчилна.
- Давхар тоолол үүсгэхгүй байх reconciliation тайлан шаардлагатай.
- 07:00–19:00 өдөр, 19:00–07:00 шөнийн ээлж; shift_date нь ээлж эхэлсэн өдөр.

## Нээлттэй шийдвэр
- Блок/түвшин/мөргөцгийн кодын стандарт.
- Хүдэр ба хөрсний м³ хэмжилтийн эх сурвалж, баталгаажуулалтын журам.
- Excel импортын яг ашиглах загвар, баганын нэр.
- Геометрийн өгөгдлийн эх формат (DXF, SHP, GeoJSON эсвэл зураг).
- Албан тушаал тус бүрийн нарийн CRUD болон approve эрх.
- Supabase байгууллага, бүс нутаг, төсөв.
